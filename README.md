# 🎬 Hybrid OTT Movie Recommendation System

### Discover Movies That Match Your Mood, Time & Interests!

A personalized Hybrid OTT Movie Recommendation System built using Python and Machine Learning. This project helps users discover relevant movies through multiple recommendation factors and an interactive Streamlit interface.

## ✨ Features

- 🎭 **Mood-Based Recommendations** – Discover movies according to your mood.
- ⏰ **Time-Based Recommendations** – Get movie suggestions based on different times of the day.
- 👥 **Social Recommendations** – Explore movie suggestions based on social viewing preferences.
- 🧠 **TF-IDF Based Recommendation** – Uses text-based feature extraction for movie recommendations.
- 🎥 **Top Movie Suggestions** – Displays personalized movie recommendations.
- 🖥️ **Interactive UI** – User-friendly interface developed with Streamlit.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Jupyter Notebook

## ⚙️ Installation & Execution

### 1. Clone the repository

```bash
git clone https://github.com/nandanichirag12-ship-it/Hybrid-OTT-Movie-Recommendation-System.git
```

### 2. Navigate to the project directory

```bash
cd Hybrid-OTT-Movie-Recommendation-System
```

### 3. Install dependencies

```bash
pip install streamlit pandas numpy scikit-learn
```

### 4. Run the application

```bash
streamlit run app.py
```

### 5. Open in browser

```text
http://localhost:8501
```
